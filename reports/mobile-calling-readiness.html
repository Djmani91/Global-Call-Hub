Android and iPhone calling

Live native calling is blocked, not delivered. The Expo preview remains available. No calls were placed, no numbers were bought, and no Twilio routing, push credentials or account settings were changed.

Build route and compatibility

Linea declares Expo 58, React Native 0.88.0 and React 19.3. Twilio Voice React Native SDK 1.8.1 is the latest stable release found in the current official changelog. SDK 1.8+ supports Expo through a native configuration plugin and supports React Native's New Architecture. The official exercised matrix covers Expo 52–57 and React Native through 0.86.3 via Expo; bare React Native 0.83.6 is also listed. Expo 58 / React Native 0.88 is outside that verified matrix, not proven incompatible.

The provider-supported route is a custom installed native binary with the Twilio plugin/native wiring. Expo Go does not include that native code. Under this project's current Replit/Expo workflow constraints, a custom development build, prebuild and native project generation are not authorized. Replit's documented iOS Launch/TestFlight route does not establish Twilio compatibility for this SDK; Google Play publishing is not currently supported by Replit's documented flow. The connected Expo tools are not evidence that this project's native route is approved.

Required decision: establish an explicitly approved custom-native workflow that preserves this Expo Go preview, then validate Twilio's plugin against Expo 58 without a downgrade. Both Android and iPhone need actual build evidence. No SDK, native plugin, EAS configuration, native projects or native calling controls were installed.

Completed server foundations

  • Provisioned managed Clerk customer authentication and wired real session verification into Express. The Voice token route requires a verified customer session; local demo profile fields and client identity headers are not authentication.
  • Added a persistent, server-owned number assignment table with a unique number key and revocation field, plus customer-filtered outgoing and number-filtered incoming resolution helpers. The development schema was applied successfully. No customer assignments were invented and no public assignment endpoint exists.
  • Added a deterministic opaque Voice identity derived from the authenticated customer ID. Offline token preparation uses the official Twilio server helper, a five-minute TTL, an application grant and a platform push credential. It was tested with fixture keys only.
  • The HTTP token endpoint does not issue tokens. It rejects identity/caller-ID overrides and returns 503 for valid authenticated requests. There is no environment switch that enables calling.
  • Prepared form-encoded Twilio webhook verification using all supplied flat fields, the configured account Auth Token and canonical HTTPS origin. Host and forwarded-host headers cannot change the signed URL. Missing/forged signatures, account mismatch and non-form requests fail closed.
  • Even valid signed callbacks return only Reject TwiML. There is no reachable Dial, Redirect, REST call creation or recording path. Replayed callbacks likewise cannot connect calls.
  • Preserved the API specification/code-generation workflow and regenerated the client and validation schemas. Pricing behavior was not changed. Corrected the post-merge database package target so the additive schema can be applied after merge.

Important limits: server session authentication is implemented, but mobile sign-in/sign-up UI and session transport are not connected. Assignment helpers and offline signing are preparation components, not live end-to-end routing. No deployed webhook, production session, real token registration or phone call was verified.

Trial-account restrictions

Because account type cannot be read, trial eligibility is unresolved. Current Twilio trial documentation limits calls to verified numbers and in-country calling, and describes restricted custom TwiML, including blocked Dial Number and Dial Client nouns. It also lists trial quotas and expiration. These restrictions can prevent this product's required international/PSTN-to-app flow. Confirm the actual account's trial program and upgrade requirements before approving any real-device call. No upgrade or verification call was initiated.
